# Study Room

**Live: https://syl-cmyk.github.io**

A one-page site built around an interactive "Study Room": an hour-by-hour task table with an example day and a "Try it yourself" mode that lets a visitor build their own schedule, saved only in their own browser. Built with plain HTML, CSS, and JavaScript, driven with Claude Code.

See `DECISIONS.md` for how and why it was built, and `verification/` for proof the live site works.
